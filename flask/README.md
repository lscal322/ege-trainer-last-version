# Тренажёр ЕГЭ — дипломный проект

Приложение Flask с интерфейсом на русском. В Replit веб-сервис использует
PostgreSQL; локальный SQLite-снимок нужен для тестов и добавления учебного контента.
React-шаблон не используется для работы приложения: веб-сервис обслуживает Gunicorn.

## Возможности

Четыре предмета, тесты обеих частей, экзамен с таймером, тренировка по номеру
задания, адаптивная практика, банк ошибок, аналитика, рейтинг, сочинения,
однократная повторная отправка после проверки, новости и кабинет преподавателя.
Учебный банк не является полноценным официальным вариантом КИМ. Процент
правильных ответов — внутренний
показатель тренажёра, не официальный тестовый балл ЕГЭ. Самопроверка сочинения
по русскому использует критерии К1–К10 и максимум 22 балла. Это чек-лист и
ручная проверка, не автоматический анализ сочинения.
Для остальных предметов развёрнутые ответы используют учебную шкалу,
не официальную предметную.

## Запуск в Replit

Веб-сервис: `artifacts/ege-trainer: web`, главная `/`, приложение `/py/`.
Среда Python 3.12, зависимости зафиксированы корневым `uv.lock`.

- `pnpm --filter @workspace/ege-trainer run dev` — Gunicorn с одним worker.
- `pnpm --filter @workspace/ege-trainer run test` — регрессионные проверки
  во временной копии SQLite, пользовательские данные не изменяются.
- `pnpm --filter @workspace/ege-trainer run typecheck` — проверка Python-синтаксиса.
- `pnpm --filter @workspace/ege-trainer run build` — установка фиксированных зависимостей.

Обязательный секрет: `SESSION_SECRET` в Secrets. Запасного секрета нет.
Порт читается из `PORT`. В production настроены HTTPS-only session cookies.

Для локального запуска: Python 3.12+, установить `requirements.txt`, задать
`SESSION_SECRET`, запустить `EGE_DB_DRIVER=sqlite python app.py` из этой папки.
SQLite лежит рядом с `app.py`, либо путь задаётся через `EGE_DB_PATH`.
В Replit не задавайте `EGE_DB_DRIVER=sqlite`: приложение подключается к
управляемой базе через `DATABASE_URL`.

## Администратор

Администратор с фиксированным паролем больше не создаётся. Старый аккаунт
с известным из исходника паролем заблокирован. Для своего администратора:

1. Зарегистрировать обычный аккаунт через сайт.
2. В Shell Replit из корня проекта выполнить:
   `uv run --no-sync flask --app artifacts/ege-trainer/flask/app.py make-admin`
3. Ввести email зарегистрированного аккаунта. Пароль не требуется передавать
   через Shell: используется пароль, выбранный при регистрации.

Альтернатива из этой папки: `python -m flask --app app make-admin`.
Команда работает с PostgreSQL текущей среды.

## Публикация и база данных

Настройки production находятся в `.replit-artifact/artifact.toml`. Публикацию
завершает владелец через Publish; Flask требует серверный запуск, не Static.
Веб-сервис подключается к PostgreSQL среды через `DATABASE_URL`, поэтому новые
результаты и аккаунты хранятся вне файловой системы приложения.

Development и production используют отдельные PostgreSQL-базы. Публикация
обновляет приложение и схему через Replit; она не означает копирование
пользовательских записей из одной среды в другую. При запуске приложение
добавляет отсутствующие учебные материалы из SQLite-снимка, не изменяя и не
удаляя существующие учебные и пользовательские записи.

Команда `make-admin` работает с PostgreSQL текущей среды. Для production
аккаунт и роль администратора должны быть настроены именно в production-среде.

## Исправления

- Атомарная серверная проверка и фиксация конкретного набора вопросов.
- Повтор отправки возвращает сохранённый результат без дополнительных XP.
- Пропущенные вопросы входят в знаменатель и считаются неверными.
- Экзамен проверяет владельца, предмет, набор заданий и серверный срок.
- Повторное открытие незавершённого экзамена не сбрасывает его срок.
- Тренировки сохраняют попытки, XP, ошибки и итог сессии.
- CSRF-защита форм и JSON, непрозрачные серверные сессии в SQLite.
- Защита от перебора входа, ограничение ввода, ошибки без SQL-деталей.
- Сохранение справочника без удаления/дублирования на каждом старте.
- Исправлены поля разборов и шесть некорректных заданий исходного банка.
- Критерии русского сочинения обновлены по материалам ФИПИ 2026 до 22 баллов.
- Комментарии, варианты и разборы не вставляются в DOM как непроверенный HTML.
